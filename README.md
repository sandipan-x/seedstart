# SeedStart

Enter your last frost date and get exact indoor seed-starting dates for 18 vegetables, with transplant timing and a succession planner. Free tool.

## Features
- 18-vegetable sowing database with indoor-start weeks, transplant timing and germination days
- Succession planting planner that lays out staggered sow dates
- Printable dated sowing log sorted earliest-first
